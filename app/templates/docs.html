Getting started

MyCTF teaches penetration testing through hands-on, isolated labs. The loop is Learn → Start Lab → Investigate → Exploit → Capture Flag → Understand → Improve.

How a challenge works

  1. Open a challenge and read the objectives.
  2. Click Start Lab to spin up your own isolated instance with a unique flag.
  3. Interact with the target in the right-hand pane (or open it in a new tab).
  4. Find and exploit the vulnerability to reveal the flag (format MYCTF{...}).
  5. Submit it on the left. Points are awarded once; a debrief with remediation unlocks.

Per-session flags

Each lab instance has its own flag tied to your account, so sharing a flag never completes someone else's challenge. Validation happens on the platform backend — exploiting a lab cannot shortcut scoring.

Safety

All vulnerable behaviour is confined to intentionally isolated training targets. Never point these techniques at systems you don't own or have explicit permission to test.
